# OUDIE Codex Skills

Use the smallest relevant skill for the task:

- `oudie-theme-architect` — theme structure, components, Liquid, design system.
- `oudie-seo-guardian` — URLs, schema, scent pages, content architecture, SEO/AEO.
- `oudie-shopify-data` — metafields/metaobjects/products/variants/events/samples/bundles.
- `oudie-mobile-ux` — mobile-first layout and responsive behavior.
- `oudie-cro` — product discovery, PDP, samples, cart/AOV, lead conversion.
- `oudie-qa` — regression, responsive, commerce, accessibility, SEO and visual QA.

Several skills may apply to one task. Example: a PDP rewrite should use theme architecture + Shopify data + mobile UX + CRO + QA.
