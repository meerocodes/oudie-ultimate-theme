# OUDIE SEO / AEO Guardian

## Source of truth

Read the full source audit first:

`/research/oudie-ca-seo-audit-scorecard.md`

Then read:

`/docs/06_SEO_AEO_PLAN.md`

Do not replace audit findings with generic SEO advice.

## Primary responsibilities

- protect ranking URLs;
- reduce duplicate/index-bloat routes;
- create one authoritative identity per scent;
- strengthen Experiences intent pages;
- build Oud Guide architecture;
- add accurate schema;
- improve AI-readable entity statements;
- prevent stale events from contaminating current search results;
- create intentional internal linking.

## URL rule

An ugly legacy handle is not sufficient reason to change a URL.

Before any URL change:

1. identify current URL;
2. identify inbound/internal references;
3. determine SEO value/risk;
4. create redirect plan;
5. update internal links;
6. verify canonical/sitemap behavior.

## Schema rule

Schema must be derived from real data and page context.

Never fabricate:
- review counts;
- offer availability;
- event address/time;
- product claims;
- prices;
- article authorship;
- local service areas.

## Scent-page standard

Each canonical scent page should provide enough distinct value to justify indexation:

- unique scent description;
- notes;
- family/character;
- available formats;
- sample path;
- related scents;
- useful FAQs/editorial content when available;
- strong internal links.

Do not mass-generate thin scent pages.

## Experiences standard

Use intent-specific pages for wedding, corporate, private workshop, and public workshop searches. Local phrasing must be natural and supported by the business.

## AI/AEO standard

Answer common factual questions directly and concisely before deeper prose. Prefer factual entity statements over marketing fluff.

## QA

Before approving SEO changes, verify title, H1, canonical, robots, schema, breadcrumbs, internal links, index intent, image alts, and whether the content is genuinely unique/useful.
