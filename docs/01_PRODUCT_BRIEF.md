# Product Brief

## Brand position

OUDIE should present as a modern oud and musk fragrance house with strong experiential credibility through its Oud Bar and fragrance workshops.

The site must support two equal but distinct business pillars:

1. **Products + fragrance knowledge**
2. **Experiences + local/event authority**

The final website should evolve from “a fragrance ecommerce store with an Oud Bar page” into:

> **A Canadian oud fragrance authority and a Toronto/GTA fragrance-experience authority.**

This direction comes directly from the SEO audit and the current strengths of the business.

## Primary user journeys

### Journey A — knows fragrance / ready to buy
Home or Search → Shop → scent → format → PDP → cart → checkout.

### Journey B — unsure what to choose
Home → Find Your OUDIE / Explore Scents → scent match → sample or scent page → format → purchase.

### Journey C — Google/AI search for a scent
Search engine / AI answer → canonical scent page → notes/story → available formats → product variant → purchase.

### Journey D — event inquiry
Google/local/social → Experiences → wedding/corporate/private workshop page → proof + service details → inquiry form.

### Journey E — education
Search/AI → Oud Guide article → relevant scents / sampling / Experiences.

## Audiences

- fragrance shoppers discovering oud/musk;
- returning OUDIE customers;
- gift buyers;
- customers who want to sample before full-size purchase;
- wedding/event planners;
- corporate activations;
- private workshop customers;
- local Toronto/Mississauga/GTA visitors.

## Experience principles

- scent identity before format complexity;
- one obvious next action per viewport;
- premium but approachable;
- editorial, not sterile;
- product education without overwhelming novice fragrance shoppers;
- strong mobile hierarchy;
- no accidental event/product blending;
- evidence and reviews near moments of uncertainty.

## Success criteria

The redesigned theme should materially improve the weak areas previously identified:

- product-card clarity;
- collection UX;
- luxury/distinctiveness;
- product discovery;
- mobile polish;
- cart/AOV;

while preserving current strengths:

- scent intelligence;
- SEO content depth;
- Experiences/local authority;
- PDP functionality;
- reviews/social proof;
- Shopify-native checkout.
