# Experiences / Oud Bar Plan

## Positioning

Experiences should feel like a legitimate service business inside OUDIE, not a promotional banner attached to the store.

The user should quickly understand:

- what the Oud Bar is;
- what happens at the event;
- what guests take home;
- which event types it fits;
- what OUDIE supplies;
- where OUDIE operates;
- how to inquire.

## Core pages

1. Experiences hub
2. Wedding Fragrance Bar
3. Corporate Fragrance Bar / Activations
4. Private Fragrance Workshops
5. Public Events / Workshops

## Service-page content framework

- specific H1 by intent;
- short value proposition;
- authentic setup/guest imagery;
- how it works;
- takeaway/customization;
- guest-count suitability where supported;
- scent-menu explanation;
- service/travel area;
- past event proof;
- reviews/testimonials;
- FAQs;
- inquiry CTA.

## Inquiry data

Collect:

- event type;
- event date;
- event time;
- city/location;
- venue/place;
- guest count;
- bottle count;
- number of scents;
- name;
- email;
- phone;
- notes.

Do not send a price automatically. The current business process is to gather context and prepare a quote for approval.

## Experience research takeaways

Competitor/service research during planning showed that strong fragrance-experience pages typically clarify:

- duration;
- guided vs self-led format;
- number/type of scent choices;
- take-home item;
- custom labels/branding when offered;
- staffing/setup;
- group-size fit;
- travel/service area.

Only include these details for OUDIE when the business has actually confirmed them.
