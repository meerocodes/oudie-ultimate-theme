# Build Roadmap

Work in phases. Do not attempt the whole theme in one uncontrolled rewrite.

## Phase A — Foundation

1. Audit current scratch files against this handoff.
2. Create final design tokens.
3. Build typography scale.
4. Build spacing/container/grid system.
5. Build buttons, form controls, chips, cards, accordions.
6. Build motion/reduced-motion rules.
7. Build accessibility focus states.

## Phase B — Global shell

8. Announcement bar.
9. Mobile-first header/drawer/search.
10. Desktop nav.
11. Footer/newsletter.
12. Breadcrumb component.
13. Reusable section spacing/layout primitives.

## Suggested first Codex implementation batch

Start with:

- design tokens;
- global CSS architecture;
- header/mobile drawer;
- homepage hero;
- first curated scent section;
- shared product/scent card.

Do not start with every page at once. Establish the visual language first, then reuse it.
