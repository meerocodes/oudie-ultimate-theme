# Copy & Claims Guardrails

## Brand voice

OUDIE copy should be:

- sensory;
- concise;
- elegant;
- approachable;
- specific;
- Middle Eastern in context without cliché;
- premium without sounding inflated.

Avoid generic luxury filler such as:

- “where elegance meets sophistication”;
- “timeless luxury redefined”;
- “unparalleled opulence”;
- vague superlatives with no evidence.

## Safe style examples

Good:

> Peach, jasmine, musk and oud with a soft floral warmth.

Good:

> Start with samples if you want to explore the collection before choosing a full-size format.

Good:

> Bring OUDIE's fragrance bar to weddings, private events and brand activations.

## Claims requiring real data

Do not state globally unless confirmed per product/record:

- 40% concentration;
- 24+ hour longevity;
- sustainable sourcing;
- Cambodian oud origin;
- “master perfumer” involvement;
- natural/organic claims;
- hypoallergenic/safe-for-sensitive-skin claims;
- guaranteed performance.

## Event/service copy

Do not promise:

- exact guest capacity;
- number of staff;
- included bottle size;
- travel range;
- number of scents;
- event duration;
- custom labels/branding;
- pricing;

unless the business data or merchant instruction confirms it.

## SEO copy

Use keywords naturally in headings/body, not repetitive location stuffing.

Preferred local language when relevant:

- Toronto
- Mississauga
- GTA
- Ontario
- Canada

Only use U.S. language where OUDIE actually services the location or content supports it.
